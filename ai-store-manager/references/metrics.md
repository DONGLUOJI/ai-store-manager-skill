# 指标与计算口径

输出数字时同时给期间、范围、单位、来源和假设。先沿用门店已定义且自洽的口径；不兼容的数据分开显示。未知成本不能当零，分母为零不能计算比例。

| 指标 | 计算或解释 | 容易误用之处 |
|---|---|---|
| 客单价 | 同期净销售额 / 同期有效成交订单数 | 不用员工数或进店人数做分母；退款订单处理需一致 |
| 到店转化率 | 同期成交到店顾客数 / 同期有效进店顾客数 | 订单与人数可能不一致；没有人数数据就不算 |
| 毛利 | 净销售额 - 已售商品成本 | 未扣租金等支出，不能称净利润；税费处理一致 |
| 毛利率 | 毛利 / 净销售额 | 前后商品和渠道结构可能改变 |
| 订单贡献 | 净销售额 - 对应商品/服务变动成本 - 渠道费用 - 配送/包装等变动成本 | 优惠已体现在净销售额则不要再扣；未含固定支出需说明 |
| 活动贡献增量 | 活动期贡献 - 可比基线贡献 - 未计入的活动执行成本 | 核销订单不一定是新增订单，避免重复扣活动费用 |
| 获客成本 | 可归属获客支出 / 可归属新增成交客户数 | 曝光和咨询不能直接视为新增客户 |
| 复购率 | 指定客户群在指定观察窗内再次购买的人数 / 该群可观察人数 | 客户群、起始日和观察窗必须相同 |
| 人时销售产出 | 净销售额 / 全店相关员工总工作小时 | 单位元/人时，不是元/营业小时或个人贡献 |
| 库存位置 | 可售现货 + 周期内可用在途 - 已承诺数量 | 过期、不可用和延期货物应排除 |

## 促销测算

使用一致范围的单笔贡献 `c` 和尚未计入的活动固定执行成本 `F`。在 `c > 0` 且贡献可视为稳定的假设下，覆盖该成本所需新增订单约为 `向上取整(F / c)`。若 `c <= 0`，不能用增加订单数解释回本。涉及原价订单转成折扣单时，另算被替代订单的贡献损失。

示例仅用于说明计算：活动售价 30 元，商品成本 12 元，渠道费用 3 元，包装 1 元，则单笔贡献为 14 元；额外固定执行成本 140 元，需要约 10 笔真正新增订单才能覆盖它。它不是这家门店的实际数据或收益预测。

## 补货测算

连续监控且供货周期相对可用时：

- 补货点 = 供货提前期内预计需求 + 有依据的缓冲量。
- 定期检查时的目标库存 = 检查间隔加供货提前期内预计需求 + 有依据的缓冲量。
- 建议订量 = `max(0, 目标库存 - 库存位置)`，再检查包装单位、起订量、可售期限、资金和容量。

平均日销量乘供货周期是平均提前期需求，不能直接称安全库存。缓冲量需要需求波动、交期或门店确认的假设；不伪造精确统计模型。易损商品要逐批考虑到货与可售期限。

教学算例：日均 20 件，供货 2 天，每 1 天检查一次，门店暂定缓冲 10 件；现货 25、有效在途 10、已承诺 5。目标库存为 70，库存位置为 30，初步缺口为 40 件；还需检查保质期与起订量，不能直接发采购单。

## 时间与 AI 成本

按任务频次算节时：周报每周节省 2 小时，不能记为每天节省 2 小时。节时、人时成本折算、实际减少支出、新增贡献分开列。工具费、设置/维护、人验收和错误返工都可能增加成本。

没有减少实际支出或验证新增贡献时，只报告效率变化，不宣称已经赚钱或回本。
