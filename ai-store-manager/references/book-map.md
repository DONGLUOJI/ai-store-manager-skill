# 《AI店长》与 Skill 的关系

本 skill 基于董逻辑《AI店长：用AI重做门店经营》的任务框架，以门店当前事实和可复算记录执行，不把书中教学案例自动升级成行业结论。流程可独立运行，不要求预先拥有完整电子书。

## 按任务找章节

| 任务 | 阅读章节 | 可转成的工作材料 |
|---|---|---|
| 开始用 AI 与分工 | 第 1、2 章 | 任务背景、样例、验收条件、人机分工 |
| 营销获客 | 第 3、4 章 | 喂料包、活动方案、沟通草稿和承接流程 |
| 排班与带教 | 第 5、8 章 | 岗位约束、练习与验收、SOP |
| 经营诊断与复盘 | 第 6 章及附录 D | 经营记录、异常假设、试点复盘 |
| 商品采购 | 第 7 章 | 商品结构、补货输入、供应商比较 |
| 多店复制与知识维护 | 第 8、9、10 章 | SOP 版本、门店差异、权限和知识更新 |

需要逐字引用或核对章节时，优先使用用户指定的书稿或档案中的 `book_path`；只在用户指定目录或当前项目查找。不存在时说明无法核对原文，不猜引文和页码。

## 使用书中材料

书中方法可作为分析框架；引用案例或数字前应核对出处、计算口径和适用条件。教学示例不能称为真实门店效果，节省时间不能直接计为现金收益。经营建议以用户提供的当前门店事实及可复算数据为准；引用最新工具或平台信息需重新核对日期。

## 新素材如何进入

用户补充素材时记录：来源、日期、门店范围、适用任务、公开范围、事实/假设/教学性质、指标及期间。客户个体资料按任务最小化使用；跨店分享优先用汇总及匿名示例。

先把素材放入对应门店档案。用户要把它提升为通用方法或更新本 skill 时，再核对证据、适用条件与反例，修改相关流程并重测；不自动上传客户资料或改写书稿。
